三方下载链接：按国家选平台

运营在后台按 US-美国-T1 这种标签，给每个国家人工绑 A–F 平台。用户触发下载话术时，系统用 {{app_download_url}} 发出对应链接。

T1 高优先市场 T2 次优先市场 T3 其余国家 判断 发出链接

一、现行发链接顺序

已上线

例如 US-美国-T1 → A，MX-墨西哥-T2 → B。

和没开国家路由时一样。

↓

话术正文不改。国家只选平台，平台才有网址。

二、国家标签：码-中文-档位

人工筛选用

后台下拉和已保存列表都显示这个标签。档位只方便你筛选和分配，不会自动整档绑同一个平台。

T1 高优先市场

例如 US-美国-T1、IT-意大利-T1、GB-英国-T1、AU-澳大利亚-T1。和用户列表同一套 T1 名单。

T2 次优先市场

例如 MX-墨西哥-T2、PE-秘鲁-T2、BR-巴西-T2、PH-菲律宾-T2。

T3 其余国家

不在 T1/T2 名单里的，例如 CN-中国-T3、IN-印度-T3、VE-委内瑞拉-T3。

三、你怎么人工分配

AI 话术页
步骤你做什么系统做什么
1. 筛档位 点 T1 / T2 / T3 / 全部档位 下拉只出现这一档的国家
2. 选国家 选 MX-墨西哥-T2 这种标签 记下这个 ISO 码，例如 MX
3. 选平台 选 A–F 里的一个 国家指向平台，不另存一条 URL
4. 保存 点「保存这条路由」 该国用户下次发下载话术，用这个平台的链接
5. 改链接 仍在「三方平台下载链接」里改 A–F 的网址 所有指向这个平台的国家一起变
一条一条绑。不会因为同是 T2 就自动发同一个平台。你随时可以改或删除某一行。

四、例子

例US-美国-T1 → A平台

已标美国的用户，下载话术发 A 的链接。

例MX-墨西哥-T2 → B平台

已标墨西哥的用户，发 B 的链接。秘鲁另存一行才能跟墨西哥一样。

例没有国家 / 没配

查不到路由，跟接待号绑定；号也没绑，就发默认 A。

五、明确不做的事

不按 IP 定位只看已经打上的号码国
不看用户自述国家自述继续只给聊天和约见
不按档位自动发链接T1/T2/T3 只是标签，平台必须人工选
不给每个国家单独存 URL国家选平台，平台才有网址
不改话术正文还是 {{app_download_url}}
